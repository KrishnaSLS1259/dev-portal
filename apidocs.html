📘 Introduction

Welcome to the API documentation for POST Employee Data to Sodales. Using this API your application can send employee data.

🚀 Getting Started

Authentication: [Bearer Token]
Token URL: https://tokenhostname/oauth2/api/v1/token
Base URL: https://apihostname/http/{URI-parm}/employees

🔗 Endpoints

POST /employees

Create a new employee record

📑 Employee Data Schema

Field Type Description Example
employeeName string Full name of the employee John Michael Smith
employeeId string Unique employee identifier EMP-2024-001
employeeEmail string Official email address john.smith@company.com
employeePhoneNumber string Primary phone number +1-555-123-4567
position string Job position Senior Software Engineer
division string Division within the company Technology
department string Department name Software Development
unit string Unit or team Backend Services
firstName string Employee’s first name John
lastName string Employee’s last name Smith
city string City of residence Toronto
postalCode string Postal/ZIP code M5V 3A8
dateOfBirth date Date of birth (YYYY-MM-DD) 1985-06-15
address string Street address 123 Main Street, Suite 400
province string Province/State Ontario
homePhone string Home phone number +1-555-987-6543
gender string Gender Male
supervisorsName string Supervisor’s full name Sarah Johnson
supervisorsId string Supervisor’s employee ID EMP-2020-045
supervisorEmail string Supervisor’s email sarah.johnson@company.com
supervisorsPhone string Supervisor’s phone number +1-555-234-5678
occupation string Occupation title Software Engineer
dateHired date Date of hire 2022-03-01
jobTitle string Job title Senior Software Engineer
sickBankRefreshDate date Date when sick bank refreshes 2026-01-01
typeOfWorkSchedule string Work schedule type Full-Time
absenceBalanceHoursSickTime90 number Sick time balance (90%) 45.5
absenceBalanceHoursSickTime100 number Sick time balance (100%) 30.0
jobCode string Job code identifier IT-DEV-003
disabilityManagerName string Disability manager’s name Michael Brown
disabilityManagerId string Disability manager’s ID DM-2023-012

⚠️ Error Handling

Status Code Error Description
400 Bad Request The request was invalid or missing required parameters.
401 Unauthorized Authentication failed or user does not have permissions.
404 Not Found The requested resource could not be found.
500 Server Error An internal server error occurred while processing the request.
503 Downstream Server Down The service is temporarily unavailable due to downstream issues.
