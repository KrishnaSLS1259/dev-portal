📘 Introduction

Welcome to the API documentation for POST Employee Data to Sodales. Using this api your application can send employees data.

🚀 Getting Started

Authentication: [Bearer Token]
Token URL : https://tokenhostname/oauth2/api/v1/token
Base URL: https://apihostname/http/{URI-parm}/employees

🔗 Endpoints

POST /employees

Retrieve user details
